오프라인 테마 미리보기

이 파일은 Vue 개발용 화면이라 파일 경로를 직접 열면 실행되지 않습니다. 앱 또는 AI 백엔드는 실행하지 않습니다.

프로젝트의 frontend 폴더에서 다음 명령으로 미리보기 서버를 시작하세요.

npm run dev -- --host 127.0.0.1 --port 5174 --strictPort

그다음 테마 미리보기 열기를 누르세요. 서버가 꺼져 있으면 이 주소도 연결되지 않습니다.

설정·파일·클립보드는 메모리 모의 데이터만 사용하며, 모델 생성·다운로드·외부 연결은 차단됩니다. 새로고침하면 미리보기 설정은 초기화됩니다.
