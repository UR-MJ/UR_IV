# AI 어시스트 공통·기능별 지침

설정 → AI 어시스트 → AI 어시스트 지침에서 작성하고 명시적으로 저장한다.
모든 입력란의 초기값은 빈 문자열이며, 지침이 없으면 기존 시스템 프롬프트를 그대로 사용한다.
기존 대화 지침을 복사하거나 변경하지 않는다.

## 적용 범위와 순서

| 기능 | 저장 키 | 사용자 지침 조합 |
| --- | --- | --- |
| 태그 확장 | `expand` | 공통 + 태그 확장 |
| 유사 태그 추천 | `suggest` | 공통 + 유사 태그 추천 |
| 자연어 → 태그 | `nl2tags` | 공통 + 자연어 → 태그 |
| 자연어 캡션 | `nl_caption` | 공통 + 자연어 캡션 |
| 영문 장면 묘사 | `nl_scene` | 공통 + 영문 장면 묘사 |
| 한↔영 번역 | `translate` | 공통 + 한↔영 번역 |
| 창의 생성 | `creative` | 공통 + 창의 생성 |
| 네거티브 추천 | `negative` | 공통 + 네거티브 추천 |
| 생성 전 자동 자연어 변환 | `auto_nl` | 공통 + 자연어 캡션 + 자동 변환 |

실제 요청은 기존 기능용 시스템 프롬프트에 해당 사용자 지침을 더한다.
내용 규칙이 충돌하면 사용자 지침이 기존 기본 내용 규칙보다 우선하며,
기능별 지침은 공통 지침을 구체화한다. 자동 변환 전용 지침은 캡션 지침보다 구체적이다.
다른 기능에 저장한 지침은 포함하지 않는다.

태그만 반환하는 기능의 쉼표 목록, 자연어 기능의 문장 출력 등 앱이 사용하는
출력 형식은 유지한다. 따라서 태그 입력용 버튼에 한국어 해설을 함께 출력하라는
지침은 적합하지 않다. 원하는 장면·태그 선택·보존/제외 기준 위주로 작성한다.
지침은 모델에 전달하는 요청이지, 모델의 준수나 태그 정확성을 보장하는 필터는 아니다.

대화(`chat_stream`)와 Batch/Upscale 이미지 캡션(`caption_image`)은 적용 범위 밖이다.
생성 전 자동 변환은 수동 생성과 Python 자동화 경로 양쪽에 동일하게 적용한다.
이미 진행 중인 요청은 시작 당시의 지침을 유지하고 다음 요청부터 저장한 내용을 읽는다.

## 저장과 경계

- 기존 `config/ui_prefs.json`의 `aiAssistInstructions` 한 키 아래에 저장한다.
- 구조: `{ "common": "", "features": { "expand": "", ... } }`.
- 각 입력란은 최대 8,000자이다. 저장 시 형식과 허용된 기능 이름을 검증한다.
- 다른 설정 키를 보존하며 기존 설정 파일이 손상된 경우 덮어쓰지 않는다.
- `getAiAssistInstructions` / `saveAiAssistInstructions`는 JSON 결과를 반환한다.
  저장 성공 응답은 실제 파일 저장이 완료된 뒤에만 보낸다.
- 데스크톱과 인증된 웹 브리지에서 같은 API를 사용한다.
- `core/ai_assist_instructions.py`에 정규화·저장·합성 규칙을 모으고,
  `OllamaWorker`가 요청별 스냅샷을 만들어 `OllamaClient.enhance`에 전달한다.
- Ollama의 일반 채팅, system 역할을 user에 합치는 호환 경로,
  generate API 재시도 모두 같은 지침 조합을 전달한다.

## 검증 범위

자동 테스트는 임시 설정 파일과 모의 HTTP 응답을 사용한다.
개인 설정, 실제 모델, GPU 또는 네트워크 추론을 변경하지 않는다.
`frontend/dev/creator-integration.html`은 화면 검증용 메모리 브리지만 제공하며
실제 제품 빌드에는 포함되지 않는다.

### 2026-09-05 검증 결과

- 전체 Python: 1,294개 실행, 1,291 통과 / 3 건너뜀 / 실패 없음.
- 프런트엔드: 20개 파일, 137개 테스트 통과.
- 이번 Python 변경 8개 파일 문법 검사, Vue 타입 검사, 제품 빌드 통과.
- 지침 전용 Python 22개는 수동 버튼 8종, 자동 변환 2개 진입점,
  요청 스냅샷, 3단계 API 호환 경로, 대화/배치 격리, 저장 실패 보존을 포함한다.
- 브라우저: 입력란 10개, 명시 저장, 미저장 상태, 기능명 검색 이동,
  다크/라이트 및 390px 단일 열 배치를 확인했다. 새 패널 내부 가로 넘침과
  브라우저 콘솔 오류는 없었다. 검증은 개발용 메모리 브리지에서 진행했다.
- `config/ui_prefs.json`, `config/gallery_last_folder.txt` SHA-256 변경 없음.
- 실제 Ollama 추론, 실제 앱 프로세스 재시작, Git 커밋/푸시는 수행하지 않았다.
