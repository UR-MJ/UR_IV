# 실험 · 손 형태 재구성

Inpaint 탭의 접힌 **실험 · 손 형태 재구성** 패널. 기본 꺼짐이며 사용 여부를 자동 저장하지 않는다.
한 번에 손 하나의 전체 윤곽·손가락 뿌리·손목 연결부를 마스킹하고 후보를 생성한다.
후보를 크게 비교한 뒤 선택한 결과만 `OUTPUT_DIR/hand_reconstruction`에 새로운 PNG로 저장한다.
원본 파일·캔버스는 자동 교체하지 않는다.

## 처리 방식

1. 표시 방향에 맞춘 원본과 같은 크기의 수동 마스크를 검증한다.
2. 마스크 주변 문맥을 포함해 자르고, 마스크 안의 기존 RGB를 중립색 127로 완전히 지운다.
3. 종횡비를 유지해 64배수 크기로 맞춘 뒤 현재 모델로 masked img2img를 실행한다.
4. 결과를 원본 해상도로 되돌려 사용자 마스크 안쪽에만 합성한다. 경계 완화는 마스크 밖으로 확장하지 않는다.
5. 각 후보는 같은 입력에서 seed만 바꿔 독립 생성한다. 자동 점수·자동 채택은 없다.

기본값: 강도 0.9, 후보 2개, 주변 여백 64px, 처리 영역 긴 변 768px, 안쪽 경계 완화 4px.
강도 범위 0.65–1.0, 후보 1–4개, 처리 해상도 512/768/1024px.
모델·샘플러·TE·VAE·LoRA와 지원되는 Anima/NegPiP 샘플링 설정은 현재 T2I 설정을 캡처한다.
Hires, ADetailer, SAM3, 품질 프리셋의 후속 패스는 이 실험에 끼워 넣지 않는다.

## 범위와 안전장치

- 자동 손 검출·손가락 개수 판정·해부학적 정확성 보장이 **아니다**. 포즈나 주변 물체도 함께 확인해야 한다.
- 마스크 밖의 여분 손가락은 그대로 남는다. 필요한 손 전체를 포함해야 한다.
- 새 손이 마스크 경계를 넘어가면 잘리거나 손목 연결이 어색할 수 있다. 충분한 범위를 선택하고 후보를 직접 확인한다.
- PNG/JPEG/WebP는 원본 바이트를 읽어 메타데이터와 투명 픽셀을 보존한다. 지원하지 않는 표시용 형식은 경고와 함께 캔버스 PNG로 변환되며, 원본 읽기 실패를 이 변환으로 숨기지 않는다.
- Forge/WebUI와 앱 기본 ComfyUI 생성 경로를 사용한다. Krea2·사용자 Comfy I2I workflow는 지원하는 척 실행하지 않고 명시적으로 거부한다.
- 네이티브 앱 전용. 웹 클라이언트에는 파일 처리 액션·신호를 공개하지 않는다.
- API에는 이미 검증한 이미지 data URL의 바이트만 보내고 임의 입력 경로·외부 이미지 URL을 받지 않는다.
- 이미지 최대 16MP/파일 64MB, 요청 128MB, 후보 캐시 128MB. 원본·마스크 해상도가 다르면 거부한다.
- 공유 생성 잠금은 모든 후보와 진행 중인 요청 종료까지 유지한다.
- **후속 후보 취소**는 현재 API가 끝날 때까지 기다리고 늦은 결과를 폐기한다. 다른 Forge 사용자의 작업을 중단할 수 있는 전역 interrupt를 보내지 않는다.
- Comfy 서버는 기본 SaveImage와 업로드 경로에 입력·후보 파일을 남길 수 있다. 앱에서 저장하지 않았다고 서버 사본까지 없다는 뜻은 아니다. 서버 파일을 임의 삭제하지 않는다.
- 소스·마스크·패널 설정 변경은 이전 후보를 무효화한다. 저장은 서버 캐시에 있는 정확한 요청 ID/후보 번호만 허용하고 파일을 덮어쓰지 않는다.

## 검증 도구

`venv/Scripts/python.exe scripts/smoke_hand_reconstruction.py`는 사용자 이미지 없이 합성 입력으로 경계 밖 픽셀 동일성·크롭·원본 보존을 검사한다.
`--live-forge http://127.0.0.1:7860`를 명시하면 유휴 로컬 Forge의 이미 선택된 모델로 512px 후보 한 개를 추가 검증한다. 체크포인트 변경·다운로드·interrupt는 하지 않는다.
이 검사는 API/합성의 동작 증거이지, 실제 손 교정 성공률 벤치마크가 아니다.

`frontend/dev/theme-audit.html`의 손 재구성 응답은 원본을 복제한 모의 후보다. 비교·오류·테마 UI만 검사하며 실제 생성이나 파일 저장은 하지 않는다.
